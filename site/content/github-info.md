## Recent Updates

### Collaboration

- **Stacked pull requests are now generally available** — break large changes into a chain of smaller, reviewable PRs that merge in order. Great for keeping reviews focused.
  _Source: [GitHub Changelog, Oct 6](https://github.blog/changelog/2026-10-06-stacked-pull-requests-generally-available)_

- **Archive pull requests** — users with Triage role or higher can now archive pull requests to reduce clutter without losing history.
  _Source: [GitHub Changelog, Oct 8](https://github.blog/changelog/2026-10-08-triage-role-users-or-higher-can-now-archive-pull-requests)_

- **Draft pull requests count toward limits** — keep this in mind when planning your team's open PR limits.
  _Source: [GitHub Changelog, Oct 8](https://github.blog/changelog/2026-10-08-draft-pull-requests-count-toward-pull-request-limits)_

### GitHub Copilot

- **Local sandboxing for GitHub Copilot is now generally available** — Copilot can run code locally in a secure sandbox when completing agentic tasks.
  _Source: [GitHub Changelog, Oct 7](https://github.blog/changelog/2026-10-07-local-sandboxing-for-github-copilot-now-generally-available)_

- **Claude Haiku 5.5 added to GitHub Copilot** — a new fast, lightweight model option now available for Copilot users.
  _Source: [GitHub Changelog, Oct 7](https://github.blog/changelog/2026-10-07-claude-haiku-5-5-in-github-copilot)_

- **Discover local models in GitHub Copilot CLI** — the CLI can now surface locally running models so you can use them directly with Copilot.
  _Source: [GitHub Changelog, Oct 7](https://github.blog/changelog/2026-10-07-discover-local-models-in-github-copilot-cli)_

- **Copilot code review: API support and new default effort level** — the code review feature now exposes an API and ships with an improved default effort setting.
  _Source: [GitHub Changelog, Oct 2](https://github.blog/changelog/2026-10-02-copilot-code-review-api-support-and-new-default-effort-level)_

- **ReviewBench: an open benchmark for AI code review** — GitHub published an open benchmark to measure how well AI models review code.
  _Source: [GitHub Blog](https://github.blog/ai-and-ml/github-copilot/reviewbench-an-open-benchmark-for-ai-code-review/)_

- **Build custom workflows with canvases** — the GitHub Copilot app lets you create canvas-based custom workflows without writing YAML.
  _Source: [GitHub Blog](https://github.blog/ai-and-ml/github-copilot/github-copilot-app-for-beginners-how-to-build-custom-workflows-with-canvases/)_

### Security

- **Purpose-built model for leaked secret detection** — GitHub now uses a dedicated ML model to detect secrets across your code and commits.
  _Source: [GitHub Changelog, Oct 7](https://github.blog/changelog/2026-10-07-purpose-built-model-for-leaked-secret-detection)_

- **Secret scanning adds detectors for Lovable, Supabase, and more** — expanded coverage for secrets from popular developer services.
  _Source: [GitHub Changelog, Oct 5](https://github.blog/changelog/2026-10-05-secret-scanning-adds-detectors-for-lovable-supabase-and-more)_

- **AI-powered fuzzing with GitHub Security Lab Taskflow Agent** — GitHub's open-source AI agent found 24 Android vulnerabilities using automated fuzzing.
  _Source: [GitHub Blog](https://github.blog/security/application-security/ai-powered-fuzzing-with-the-github-security-lab-taskflow-agent/)_
