## October 2026 updates

### GitHub Changelog highlights

Recent improvements across GitHub products (source: [GitHub Changelog](https://github.blog/changelog/)):

- **Gemini 4 Argon in GitHub Copilot** — Google's Gemini 4 Argon model is now available in GitHub Copilot. ([Changelog, Oct 13](https://github.blog/changelog/2026-10-13-gemini-4-argon-in-github-copilot))

- **Secret scanning blocks Anthropic keys by default, adds Salesforce** — Push protection now automatically blocks Anthropic API keys, and Salesforce tokens are a new supported secret type. ([Changelog, Oct 13](https://github.blog/changelog/2026-10-13-secret-scanning-blocks-anthropic-keys-by-default-adds-salesforce))

- **GitHub App improvements for least privilege** — New controls let apps request narrower permissions and simplify app management for organizations. ([Changelog, Oct 13](https://github.blog/changelog/2026-10-13-github-app-improvements-for-least-privilege-and-management))

- **Code scanning AI Scan metrics in security overview** — Security overview now shows AI Scan coverage and alert metrics, making it easier to track automated scanning across repos. ([Changelog, Oct 13](https://github.blog/changelog/2026-10-13-code-scanning-ai-scan-metrics-in-security-overview))

- **Copilot for JetBrains: new controls and chat improvements** — JetBrains IDE users get improved chat UX and more Copilot configuration options. ([Changelog, Oct 10](https://github.blog/changelog/2026-10-10-new-controls-and-chat-improvements-in-copilot-for-jetbrains))

- **Push attribution for commits (limited public preview)** — GitHub now tracks which user triggered a push, separate from the commit author, improving audit trails. ([Changelog, Oct 12](https://github.blog/changelog/2026-10-12-push-attribution-public-preview))

- **Search and filter for spending budgets** — Teams managing GitHub billing budgets can now search and filter across budget entries. ([Changelog, Oct 13](https://github.blog/changelog/2026-10-13-search-and-filter-for-budgets-now-available))
